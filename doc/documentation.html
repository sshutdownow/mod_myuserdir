Stable version: 0.99.3

Installation instructions:

Prerequisities:

This packages are required for successufull compilation:
apache13-dev
mysql-dev

Download source code:

The latest version of mod_myuserdir is here

Building mod_myuserdir:

just type make

If you do not want php support than remove -DWITH_PHP from CFLAGS in Makefile. If you want to test module's internal caching than add -DWITH_CACHE to CFLAGS in Makefile.

Install mod_myuserdir:

make install (as root)

MySQL:

Now we create database that will store user's names their homedirs and php settings. 
CREATE DATABASE `hosting`;
USE `hosting`;

CREATE TABLE `tilde_users` (
    `username` varchar(255) NOT NULL default '',
    `homedir` varchar(255) NOT NULL default '',
    `enabled` enum('yes','no') NOT NULL default 'no',
    `extra_php_config` text,
    UNIQUE KEY  (`username`),
    KEY (`enabled`)
) ENGINE=MyISAM COMMENT='hosting ~users';

GRANT SELECT ON hosting.tilde_users TO 'nonpriv'@'localhost' IDENTIFIED BY 'M3Ga PaSsVVd';

INSERT INTO `tilde_users` VALUES ('igor', '/var/www/homedirs/igor', 'yes', 'safe_mode=1');
INSERT INTO `tilde_users` VALUES ('someone', '/var/www/homedirs/someone', 'no', 'engine=0');
Edit file tilde_users.sql and create apropriate database and tables:
mysql -u root -p < tilde_users.sql

Apache:

Edit apache config, you may use httpd.conf.add as example, make shure that mod_myuserdir.so is loaded after libphp4.so. 
LoadModule php4_module        libexec/apache/libphp4.so
LoadModule myuserdir_module   libexec/apache/mod_myuserdir.so
#...
AddModule mod_php4.c
AddModule mod_myuserdir.c
#...
#
<IfModule mod_myuserdir.c>
        MyUserOn	on
	MyUserDbHost	"localhost"
	MyUserDbSocket	"/tmp/mysql.sock"
	MyUserDbUser	"nonpriv"
	MyUserDbPass	"M3Ga PaSsVVd"
	MyUserDbName	"hosting"
	MyUserQuery	"SELECT homedir,extra_php_config FROM users WHERE username='%s' AND enabled='yes'"
#	If compiled with cache support
#	MyUserCacheOn	on
#	MyUserTTLPositive 600
#	MyUserTTLNegative 120
#
<IfModule>
The most important parameter that you should take into account is MyUserQuery, it must contain only one %s that is substituted by username that is taken from http request http://www.yourhost.domain/~username/some/path.

The module expects MySQL to return up to two fields: the first one is treated as absolute path of userdir (magically becomes open_basedir) and the second (if exist) is pairs of php variables and their values delimeted by equality sign, pairs in turn are separated by semicolon, for boolean variables you should use 1 and 0.

Make it all working:

Just restart apache:
apachectl stop; apachectl start
So, it should work now.
This module is tested to compile and work on FreeBSD and Linux with MySQL 4.[01].xx and 5.0.xx.
